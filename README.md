# Jocelyin Ramirez - Personal Portfolio Website

## Project Overview

Welcome to my personal portfolio website! This project was created to showcase who I am, my education, my experience in instrumentation and controls, and my interests in technology and automation.

The website also represents what I have learned throughout this course, including HTML, CSS, GitHub, project planning, documentation, testing, and publishing a live website through GitHub Pages.

## Project Goals

The main goals of this project were to:

- Create a functional two-page personal portfolio website.
- Practice building and styling webpages using HTML and CSS.
- Use GitHub to organize and manage my project files.
- Create project management documentation to plan and track the project.
- Publish a working website using GitHub Pages.
- Build a project that represents my education, experience, interests, and career goals.

## Website Pages

The website contains two connected pages:

- **Home Page (`index.html`)** - Introduces my portfolio and provides an overview of my background and goals.
- **About Me (`about.html`)** - Provides more information about my education, work experience, interests, and future goals.

Both pages use the same external `style.css` file and are connected through navigation links.

## What I Learned

Through this project, I learned how the different parts of a website project work together. At the beginning, I was still learning how HTML, CSS, GitHub, and GitHub Pages connected with each other. As I continued working on the project, I became more comfortable organizing files, making changes, testing my website, and fixing problems.

I also learned that planning and documentation are just as important as building the website itself. Creating the scope, project plan, and retrospective helped me understand the project from beginning to end instead of just focusing on the code.

Overall, this project helped me become more confident using GitHub and working with HTML and CSS. It also gave me a better understanding of how planning, testing, documentation, and development all work together to complete a project.
