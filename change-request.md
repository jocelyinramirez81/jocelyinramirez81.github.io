# Project Change Request

## Proposed Change

The proposed change is to add an embedded Google Map to my personal website that shows my hometown. The map would be placed in a section of the website where visitors can easily see where I am from without having to leave the page.

## Reasons for the Change

Adding a Google Map would give visitors a better idea of where my hometown is located. Since my website is meant to introduce myself, I think this would make it a little more personal and give visitors another way to learn about me.

## How This Change Will Add Value

This change would make the website more interactive and visually interesting. Instead of only reading information about me, visitors would also have something they can interact with. It would also help make the website feel more complete and engaging.

## How This Change Will Affect the Constraints

**Time:** This change should not take very long to complete because Google Maps provides embed code that can be added directly to the website.

**Quality:** The change could improve the overall quality of the website by adding an interactive feature. I would still need to make sure the map fits correctly on different screen sizes and does not negatively affect the current design.

**Budget:** There should be little to no impact on the budget because embedding a basic Google Map can be done without purchasing additional software or services.
