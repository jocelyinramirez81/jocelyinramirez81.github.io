# Project Plan

## Project Title
Jocelyin Ramirez Personal Portfolio Website

## Project Overview
This project is a personal portfolio website that introduces who I am, my education, my experience in instrumentation and controls, and my interests in technology and automation. The website will have a Home page and an About Me page that are connected through navigation links.

## Project Goals
The goals of this project are to:

- Create a functional two-page personal portfolio website.
- Practice using HTML and CSS.
- Learn how to organize and manage a project using GitHub.
- Use GitHub Pages to publish a live website.
- Create a website that represents my education, experience, interests, and career goals.

## Project Tasks

### 1. Planning
- Define the purpose and scope of the website.
- Determine the content needed for each page.
- Create a project scope statement and project plan.

### 2. Website Development
- Create the Home page using `index.html`.
- Create the About Me page using `about.html`.
- Add navigation links between both pages.
- Create an external stylesheet using `style.css`.
- Add content about my education, career, interests, and goals.

### 3. Testing
- Make sure both pages load correctly.
- Test the Home and About Me navigation links.
- Check that both pages use the same CSS file.
- Review the website for formatting or content errors.

### 4. Deployment
- Store all project files in the GitHub repository.
- Publish the website using GitHub Pages.
- Verify that the live website works correctly.

### 5. Documentation
- Maintain a professional `README.md`.
- Document the project scope and project plan.
- Record project changes when necessary.
- Complete a retrospective at the end of the project.

## Resources
The main resources used for this project include:

- HTML
- CSS
- GitHub
- GitHub Pages
- Course materials and instructions

## Timeline
The project will be completed throughout the course according to the required assignments and deadlines. Each stage of the project will build on the previous work until the final portfolio website and documentation are complete.

## Potential Risks
Possible challenges include errors in HTML or CSS, broken navigation links, problems publishing through GitHub Pages, and my limited experience with some of the tools. I will address these problems by testing my work, reviewing my code, and making corrections when needed.

## Completion Criteria
The project will be considered complete when the Home and About Me pages work correctly, both pages use the same stylesheet, navigation works between the pages, the website is successfully published through GitHub Pages, and all required project documentation is included in the repository.
