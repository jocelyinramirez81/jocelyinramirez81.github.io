# Project Scope Statement

## Project Title
Jocelyin Ramirez Personal Portfolio Website

## Project Purpose
The purpose of this project is to create a simple personal portfolio website that introduces who I am, my education, my experience in instrumentation and controls, and my interests in technology and automation. I also wanted this project to help me practice HTML, CSS, GitHub, and project management skills that I can continue using throughout my education and career.

## Project Objectives
The main objectives of this project are to:

- Create a functional two-page personal portfolio website.
- Build a Home page and an About Me page.
- Use HTML to organize the content of the website.
- Use one external CSS file to create a consistent design across both pages.
- Include navigation between the Home and About Me pages.
- Publish the completed website using GitHub Pages.
- Organize the project files and documentation in one public GitHub repository.
- Apply project management concepts while planning and completing the project.

## Project Deliverables
The completed project will include:

- `index.html` for the Home page.
- `about.html` for the About Me page.
- `style.css` for the design and styling of both pages.
- A functional website published through GitHub Pages.
- A professional `README.md` explaining the project.
- A `docs` folder containing the project scope, project plan, and retrospective.

## Project Requirements
The website must contain two connected pages that are accessible through navigation links. Both pages must use the same external stylesheet and have a consistent appearance. The website must also be functional when published through GitHub Pages and organized within a single public GitHub repository.

## Target Audience
The main audience for my website includes classmates, instructors, future employers, and anyone interested in learning more about my education, technical experience, career goals, and interests.

## Project Constraints
One of the main constraints for this project is my experience level with HTML, CSS, GitHub, and GitHub Pages. I am still learning these tools, so I needed to keep the website simple enough to complete successfully while still making it professional and functional. Time was also a constraint because the project needed to be completed by the course deadline.

## Success Criteria
I will consider this project successful if:

- Both website pages load correctly.
- The Home and About Me links work.
- Both pages use the same CSS file.
- The website is accessible through GitHub Pages.
- The repository contains all required website and documentation files.
- The final website clearly communicates who I am, my background, and my professional interests.

## Out of Scope
This project will not include advanced features such as JavaScript, user accounts, databases, online payments, or other complex web applications. The focus is on creating a simple, organized, and professional two-page portfolio using HTML and CSS.
